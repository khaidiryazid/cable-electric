Parameter

Diameter kabel otomatis diberi allowance 5% (pembulatan) sebelum dihitung, sama seperti file kamu.
B = Barrel C = Clearance T = Lilitan D = Diameter N = Layer IW = Internal Width
Barrel drum harus punya diameter ≥ faktor × diameter kabel (OD), biar kabel nggak ketekuk kelewat tajam saat dililit. Faktor umum: 6–8x (kabel fleksibel) sampai 15–20x (kabel power/armored) — sesuaikan ke datasheet kabel kamu.

Deff = ROUND(D×1.05, 0). Clearance standar C = 20mm (F<790), 40mm (F<1490), atau 50mm (lainnya). N = INT((F−B−2×C)/(2×Deff)) — bisa ditimpa manual. T = INT((IW/Deff)−1). C aktual = ((F−B)/2) − N×Deff. Panjang maksimum L = ROUNDDOWN(π×N×T×(B+N×Deff)/1000, 0) meter.
