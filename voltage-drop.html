Tabel Referensi Konduktor Tembaga (live, dari parameter konstruksi di atas)

R@20°C = data dasar dari file kamu (tidak berubah). R@70°C/90°C dikoreksi otomatis sesuai bahan konduktor. Xl dihitung dari parameter konstruksi & ukuran kabel (sedikit berbeda antara CSA di bawah dan di atas 50mm², sesuai rumus di file kamu). Klik baris untuk isi otomatis ke "Hitung Voltage Drop".
CSA nominal (mm²) R @20°C R @70°C (PVC) R @90°C (XLPE) Xl (Ω/km)
Rumus voltage drop: 3 fasa → Vd = √3 × I × L × (R·cosφ + X·sinφ) / 1000. 1 fasa → Vd = 2 × I × L × (R·cosφ + X·sinφ) / 1000. Rumus reaktansi: Xl = 2π·f·L×10⁻³ mH/km, dengan L dihitung otomatis dari konstruksi kabel (diameter konduktor & kabel keseluruhan) dan ambang ukuran di 50mm² — persis rumus di file Excel kamu. R@20°C adalah data dasar dari file (dua nilai: Cu & Al); R pada suhu operasi dikoreksi pakai koefisien 0.00393/°C (Cu) atau 0.00403/°C (Al). Arus beban dihitung dari Daya (P): I = P×1000/(V×cosφ×faktor) untuk kW, atau I = P×1000/(V×faktor) untuk kVA.
